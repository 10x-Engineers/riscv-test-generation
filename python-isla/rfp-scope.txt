# ==========================================================================
# EXCLUDED, with the reason each is not architectural test surface. Those
# inside an included prefix are listed as `-` rules above; the rest are simply
# absent from the prefixes. Listed here so the omissions are reviewable
# rather than silent.
#
#   core/rvfi_dii*.sail, postlude/fetch_rvfi.sail
#       RVFI-DII is a co-simulation *trace interface* for hardware
#       verification harnesses. It is not RISC-V architectural behaviour and
#       no generated program can exercise it -- it is driven by an external
#       harness over a socket.
#
#   postlude/device_tree.sail
#       Generates a DTB blob describing the platform. Firmware plumbing, not
#       instruction semantics.
#
#   sys/simple_interrupt_generator*.sail
#       A model-only MMIO test device (docs/SimpleInterruptGenerator.md), not
#       part of any ratified extension.
#
#   unit_tests/test_mstatus.sail
#       The model's own unit tests. Covering them measures the model's test
#       suite, not ours.
#
#   main/main.sail
#       Emulator entry point.
#
#   postlude/validate_config.sail
#       Startup validation of the JSON platform config. Reachable, and in fact
#       well covered since it runs on every boot -- excluded because it
#       describes the *configuration file format*, not the ISA. This one is
#       borderline; including it would raise the scoped number, so it is
#       excluded in the direction that does not flatter us.
#
#   prelude/errors.sail
#       Error-reporting helpers for model-internal failures.
