A note on what this is *not*: these are crosses in the model's control flow. ACT4's
`cr_rs1_rs2_edges` crosses operand *values* -- 11 edge values on rs1 against 11 on

that any single execution covers. That axis is invisible to source coverage by
construction, and is why the RVVI/SVA coverpoints are measured alongside rather than
replaced by this plan.
